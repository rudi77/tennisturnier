# tennisturnier

[![CI](https://github.com/rudi77/tennisturnier/actions/workflows/ci.yml/badge.svg)](https://github.com/rudi77/tennisturnier/actions/workflows/ci.yml)

**MATCHDAY** — ein Tennisturnier mit Freunden: anlegen, auslosen, starten,
live zählen, und alle schauen auf dem Handy mit. Geführt im Gespräch mit
einem Agenten oder direkt über die Widgets.

Alles Weitere steht in [`matchday/README.md`](matchday/README.md): starten,
Aufbau, Betrieb auf Railway, Konfiguration.

Warum es so gebaut ist, steht in den Architekturentscheidungen unter
[`docs/adr/`](docs/adr/README.md). Die ADRs 0001–0015 beschreiben die
frühere Vereinsplattform, die mit [ADR-0016](docs/adr/0016-neuanfang-ein-turnier-mit-freunden.md)
durch MATCHDAY abgelöst und inzwischen entfernt wurde. Sie bleiben als
Geschichte stehen; ihr Code ist in der Git-Historie.
